# Attribution for the files in this folder

The PET images in this folder are derived from the publicly‑available data set TCGA-PRAD hosted on The Cancer Imaging Archive (TCIA) 
and are distributed under the [Creative Commons Attribution 3.0 Unported (CC BY 3.0) licence](../../license.txt).

**Original source:**

Zuley, M. L., Jarosz, R., Drake, B. F., Rancilio, D., Klim, A., Rieger-Christ, K., & Lemmerman, J. (2016). The Cancer Genome Atlas Prostate Adenocarcinoma Collection (TCGA-PRAD) (Version 4) [Data set]. The Cancer Imaging Archive. https://doi.org/10.7937/K9/TCIA.2016.YXOGLM4Y

**Modifications**

No modifications were applied to the original PET images.

Masks (stored in `mask/`), each including one spherical ROI for SUV computation, are released under [CC BY 3.0 licence](../../license.txt). 
They were newly generated for each PET series using LIFEx v25.06.1 (https://doi.org/10.1158/0008-5472.CAN‑18‑0125) and for compatibility purposes, the headers were edited using SimpleITK (https://doi.org/10.3389/fninf.2013.00045).

**How to cite**

When you reuse any PET images from this folder, please cite the original data set(s) as shown above. 

If you use other files (i.e., the masks), do not forget to cite our repository: https://github.com/oncoray/suv_computation.
